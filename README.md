# greet-community

A friendly greeting package

## Install
Use Python 3.11 or later in an activated virtual environment.
```sh
python -m pip install -e .
```

## Use
Import `greet` from `greet_community` to greet a name.
Run: `python -c "from greet_community import greet; print(greet('Hee'))"`
Expected output: `Hello, Hee!`
